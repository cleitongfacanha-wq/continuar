Marco Regulatório • Lei Estadual nº 6.745/85

Reabilitação Funcional & Readaptação de Servidores

Critérios objetivos para diferenciar a recuperação clínica da capacidade física (reabilitação) da necessidade de adequação do posto ou lotação compatível (readaptação funcional).

🩺

1. Reabilitação Funcional

Âmbito Clínico-Terapêutico • Recuperação da Função

Processo de reabilitação e cinesioterapia laboral voltado para o servidor com queixas musculoesqueléticas. O objetivo é restaurar a amplitude articular, a força e a tolerância mecânica para que ele permaneça em seu cargo original.

Parâmetro Numérico de Reavaliação:

Aplicação seriada das escalas clínicas (EVA, QuickDASH e Roland-Morris) no início e após 60 dias de intervenção para atestar resposta terapêutica.

⚖️

2. Adaptação & Readaptação

Âmbito Ergonômico & Estatutário • Lei Estadual nº 6.745/85

Adaptação do Posto: Ajuste do ambiente físico (altura de telas, suportes e pausas) sem mudar o servidor de cargo.
Readaptação Funcional: Processo pericial junto à SES-SC para transferência formal quando a limitação do servidor é permanente.

Suporte Técnico à Perícia Oficial:

Evita readaptações precipitadas comprovando tentativas prévias de adaptação no próprio setor do hospital.

1. Histórico de Reabilitação na UDSO:
Servidora realizou 24 sessões de cinesioterapia laboral no período de 90 dias. Manteve índice de incapacidade lombar Roland-Morris = 15 (Severo) e EVA média = 6.8 em tarefas de transporte de leito, sem resposta terapêutica suficiente para atividades de alta sobrecarga.

Foram implementadas adequações de pausas ativas e orientações de biomecânica de transferência. Contudo, as exigências intrínsecas da UTI Adulto demandam levantamento de cargas superiores a 25 kg, gerando risco de agravamento da lesão discal.

Integração com Google Sheets (doGet)

Script de leitura segura das abas ANAMNESE, EVA, QNSO, DASH, OSWESTRY, ROLAND e LEFS

// Função de leitura segura para alimentar o Dashboard
function doGet(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    function lerAba(nomeAba) {
      var sh = ss.getSheetByName(nomeAba);
      if(!sh) return [];
      var data = sh.getDataRange().getValues();
      if(data.length <= 1) return [];
      var headers = data[0];
      var lista = [];
      for(var i = 1; i < data.length; i++) {
        var item = {};
        for(var j = 0; j < headers.length; j++) {
          item[headers[j]] = data[i][j];
        }
        lista.push(item);
      }
      return lista;
    }

    return ContentService.createTextOutput(JSON.stringify({
      status: "sucesso",
      timestamp: new Date().toISOString(),
      anamnese: lerAba("ANAMNESE"),
      eva: lerAba("EVA"),
      qnso: lerAba("QNSO"),
      dash: lerAba("DASH"),
      oswestry: lerAba("OSWESTRY"),
      roland: lerAba("ROLAND"),
      lefs: lerAba("LEFS"),
      agendamento: lerAba("AGENDAMENTO"),
      evolucao: lerAba("EVOLUCAO")
    })).setMimeType(ContentService.MimeType.JSON);
  } catch(erro) {
    return ContentService.createTextOutput(JSON.stringify({ status: "erro", detalhe: erro.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
